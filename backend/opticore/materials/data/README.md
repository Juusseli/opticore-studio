# Material and coating data

| File | Contents | Source and licence | Generated by |
|---|---|---|---|
| `catalog.json` | the built-in glasses, crystals and polymers | the references listed per material | maintained by hand |
| `coating_materials.json` | thin-film and metal optical constants n, k | refractiveindex.info database, CC0 1.0; the original measurement per entry | `python -m opticore.tools.coating_materials <pages>` |
| `builtin_coatings.json` | the built-in coating library with stated specifications | designed here of `coating_materials.json` | `python -m opticore.tools.builtin_coatings` |
| `stock_generic.json` | the generic stock-lens library | generated here | `python -m opticore.tools.make_stock_library` |
| `oic2019_yucca_targets.csv` | the target s-polarised transmittance of the OIC 2019 Manufacturing Problem ("Yucca problem") at 10° and 50° | see below, CC BY 4.0 | converted unchanged from the contest spreadsheet |
| `coating_examples.json` | worked coating-design examples | designed here with the coating designer | `python -m opticore.tools.coating_examples [seconds]` |

## OIC 2019 Manufacturing Problem targets

The target values of `oic2019_yucca_targets.csv` are those of the 2019 Topical
Meeting on Optical Interference Coatings Manufacturing Problem Contest:

* D. Poitras, L. Li, M. R. Jacobson, C. C. Cooksey, "2019 Topical Meeting on
  Optical Interference Coatings: Manufacturing Problem Contest", Appl. Opt.
  59(5), A31–A39 (2020), doi:10.1364/AO.59.000A31.
* Data: D. Poitras et al., Figshare, doi:10.6084/m9.figshare.9915800.v1, file
  "OIC 2019 Manufacturing Problem v2018-10-09dp2.xls" (MD5
  08112d2a8d969a49bf21ef782a3759ba), licensed under Creative Commons
  Attribution 4.0 International (CC BY 4.0,
  https://creativecommons.org/licenses/by/4.0/).

Changes: the sheet "OIC 2019 T and R Targets" was converted to CSV (angle,
wavelength in nm, target Ts, tolerance); the values are unchanged.
